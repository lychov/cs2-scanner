Как это работает (один раз настроить)
  1. Перетащи эту кнопку на панель закладок браузера: Цены CS2 → сканер
  2. Жми «Обновить реальные цены Steam» — откроется торговая площадка Steam
  3. На открывшейся вкладке Steam нажми закладку «Цены CS2 → сканер» и подожди (около 3 сек на скин)
  4. Цены сами придут сюда, и карточки пересчитаются по реальным гривнам
Цены берутся прямо из Steam в твоём браузере, в гривнах — курс для них не нужен. Хранятся в этом браузере 3 дня.

Шансы: каждый скин следующего уровня в коллекции выпадает с равной вероятностью; для ножей — каждая отделка из кейса. Цены Steam — средние цены реальных продаж за 24 часа / 7 дней (покупка считается по большей, продажа — по меньшей), не ниже 3 ₴ за штуку. Цены маркетов — самый дешёвый лот на Skinport. Всё пересчитано по твоему курсу. Средняя цена — не гарантия: перед покупкой глянь текущие лоты. Флоат выхода считается по худшему флоату внутри износа входа (режим «лучший флоат» — по лучшему). Всегда перепроверяй перед покупкой — контракт необратим.
