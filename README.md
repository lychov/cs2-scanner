# Сканер крафтов CS2

Перебирает все контракты внутри одной коллекции (10 скинов → следующий уровень, 5 красных → нож/перчатки),
считает окупаемость с учётом комиссии и показывает, где сейчас плюс.

- Данные о скинах, коллекциях, флоатах и ножах из кейсов: [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API)
- Цены маркетов: публичный API Skinport (самый дешёвый лот, без ключа)
- Цены Steam: средние цены продаж за 24ч/7д из фида CSGO Trader (`prices.csgotrader.app`). Сам Steam блокирует запросы с серверов GitHub
- Для покупки в Steam скин должен продаваться и за сутки, и за неделю; цена входа не ниже 3 ₴
- Флоат выхода считается по формуле CS2 с нормализацией и по **худшему** флоату внутри износа входа, так что цифры осторожные
- Есть режим «если поймаю лучший флоат» — показывает, сколько даст флоат-арбитраж

## Сайт, который сам обновляется (GitHub Pages)

1. Создай репозиторий на GitHub и залей туда эту папку.
2. Settings → Pages → Source: **GitHub Actions**.
3. Actions → «Scan trade-ups» → **Run workflow** (первый запуск вручную).
4. Через пару минут сайт будет по адресу `https://<ник>.github.io/<репо>/`.

Дальше он пересчитывается сам каждый час. Частоту меняешь в `.github/workflows/scan.yml` (строка `cron`).

## Локально

```bash
node scanner.mjs        # Node 18+, зависимостей нет
npx serve public        # открыть http://localhost:3000
```

## Как читать карточку

- **Вложишь** — цена 10 (или 5) входов
- **В среднем** — ожидаемая сумма на руки после комиссии
- **Шанс плюса** — доля исходов, которые дороже вложенного. 100% = в минус уйти нельзя
- **Худший** — самый дешёвый исход после комиссии

## Ограничения

- Цены Steam — средние продаж, а не текущие лоты. Перед покупкой глянь торговую площадку.
- Купленное на сторонних маркетах 7 дней нельзя кидать в контракт (Trade Protection).
- Doppler-фазы и паттерны не различаются — цена берётся по самому дешёвому лоту.
- Сканируются только контракты из одной коллекции. Смешивание коллекций — следующий шаг.
- Если Skinport начнёт отвечать ошибкой с серверов GitHub — запусти скрипт локально или поменяй источник цен в `PRICES_URL`.
